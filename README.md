# ICU 重症急救模拟器

一个基于 HTML、CSS 和原生 JavaScript 的浏览器端 ICU 床旁监护与急救操作模拟器。项目用于交互演示和学习，不连接真实医疗设备，也不能替代专业培训、临床判断或医疗建议。

## 运行

项目无需安装依赖或构建。建议在项目根目录启动本地静态服务器，以确保浏览器可正常加载 JavaScript 模块：

```bash
python -m http.server 8000
```

然后访问 <http://localhost:8000>。也可以使用其他静态文件服务器托管项目目录。

## 功能

- 实时模拟 ECG、Pleth、NIBP 和 EtCO₂ 波形，并显示心率、血氧、血压等参数。
- 切换多种模拟心律，并调整监护波形速度。
- 执行初步评估、呼叫团队、氧疗、气道管理、连接监护仪、建立静脉通路、CPR 和重新评估等模拟操作。
- 操作手动除颤仪模拟流程，包括选择能量、充电、同步、放电和取消。
- 开启自动节律模式，模拟病情事件，并查看事件日志、抢救评分和运行时间。

## 项目结构

```text
.
├── index.html
├── styles.css
└── js/
    ├── app.js
    ├── actions.js
    ├── auto-rhythm.js
    ├── manual-defibrillator.js
    ├── monitor.js
    ├── simulation.js
    └── ...
```

页面入口为 `index.html`，应用使用原生 JavaScript ES modules；监护界面、患者状态、模拟逻辑和急救操作分别由 `styles.css` 与 `js/` 下的模块实现。

## 安全说明

所有参数、波形、病情变化和除颤效果均为软件模拟。模拟能量档位及成功率不对应真实设备参数；请勿将本项目用于真实患者诊疗或临床决策。
